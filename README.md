# ИЗДЕЛИЕ 256 — Program Baseline

ОКБ-256 · Сан-Матео — Experimental Design Bureau 256, San Mateo.

First hardware program of the Chief Designer: one instrumented thrust-stand facility
and one propulsion article — a linear valveless pulsejet (Article **256Б**, Lockwood/SNECMA
family, 304 stainless) with a commercial-EDF contingency (Article **256Э**). Disciplined
test campaign with pre-test prediction, stated uncertainty, and honest correlation,
presented as a deadpan Soviet experimental-program homage.

Governing aesthetic law: **crude design, precise execution — the gap is the joke.**

## Conventions

- **Revisions are frozen.** The baseline is Rev. H. There is no Rev. I. Changes to scope
  are filed as Изделие 256В for the next five-year plan.
- **Native CAD stays in Fusion 360's cloud** (its own version history). This repo takes
  **milestone exports only** — STEP/DXF/PDF as released to a shop or machined — under
  `cad-exports/`, named like `256-02-rev-b.step`.
- **Test data** goes under `test-data/`, runs logged `256-001` onward (CSV + session notes).
- **Video stays out of the repo** (YouTube/Drive link in this README when it exists).
